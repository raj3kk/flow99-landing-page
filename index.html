FAQ

Aksar pooche jaane wale sawal.

Ye page asli Flow99 service hai?

Nahi. Ye ek standalone demo hai — sirf design aur flow dikhane ke liye. Iska live Flow99 se koi connection nahi hai.

Kya is page se asli WhatsApp message bheja ja sakta hai?

Nahi. No real sends. Yahan koi message, booking ya reminder asli me send nahi hota — sab examples preview hain.

Kya ye prices asli hain?

Nahi. Prices not real. ₹499 / ₹1,499 / ₹2,999 sirf demo labels hain, Flow99 ke actual plans nahi. Koi payment ya checkout nahi hai.

Kya meri koi jaankari save hoti hai?

Nahi. Nothing saved. Is page par koi form data collect nahi hota, koi account nahi banta, aur koi network call nahi hoti.

Kya main yahan se signup ya login kar sakta hoon?

Nahi. Login button sirf “DEMO only” label ke saath hai aur kahi link nahi karta. Koi auth, OTP ya account flow nahi hai.
